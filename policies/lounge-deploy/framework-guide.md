# Lounge Deploy 정책 가이드 `2026-08-12.1`

이 문서는 정책 `2026-08-12.1`과 같은 PR에서 발행한 사람용 가이드다. 발행 후에는 수정하지 않는다. 기계 판독 규칙은 같은 버전의 `history/2026-08-12.1.json`에 있고, 이 문서는 그 규칙을 사람이 이해하기 위한 설명이다.

이 버전은 계약 구조를 성립시키는 최초 스냅샷이다. 규칙 값의 본격적인 이관과 확장은 후속 정책 버전에서 한다.

<a id="zip-limits"></a>

## ZIP 제한

| 항목             | 값                  |
| ---------------- | ------------------- |
| 압축 크기        | 최대 30MB           |
| 압축 해제 크기   | 최대 100MB          |
| 파일 수          | 최대 500개          |
| 최상위 index.html | 반드시 존재해야 한다 |

출력 폴더 자체가 아니라 **출력 폴더의 내용**이 ZIP 최상위에 오도록 압축한다.

<a id="allowed-extensions"></a>

## 허용 확장자

정적 웹 작품에 필요한 확장자만 허용한다. 목록에 없는 확장자가 있으면 검사에 실패한다. 확장자 비교는 소문자를 기준으로 한다.

<a id="blocked-files"></a>

## 차단 파일

`.env`로 시작하는 모든 파일과 `runtime-config.js`는 ZIP에 포함할 수 없다. 공개 런타임 값이 필요하면 아래 런타임 환경변수 절차를 따른다.

<a id="path-rules"></a>

## 경로 규칙

다음 형태의 경로는 차단한다.

- 절대 경로
- 상위 디렉터리로 벗어나는 경로
- Windows 백슬래시 구분자
- 제어 문자가 포함된 경로
- URL로 재해석될 수 있는 문자가 포함된 경로
- 정규화되지 않은 경로

<a id="asset-paths"></a>

## 정적 자산 경로

작품은 라운지의 하위 경로에서 열린다. 따라서 HTML·CSS·JS가 참조하는 로컬 정적 자산은 상대 경로여야 한다. 루트 절대 경로는 경고로 보고하며, 라운지 내부 API 호출처럼 의도한 경로라면 사용자가 사유를 확인한 뒤 해제할 수 있다.

<a id="runtime-env"></a>

## 런타임 환경변수

공개해도 되는 런타임 값은 ZIP에 넣지 않고 `.env`로 별도 첨부한다. 브라우저에서는 `window.__LETS_RUNTIME_ENV__`로 읽는다. 비밀값은 어떤 경우에도 번들에 포함하지 않는다.

<a id="nextjs"></a>

## Next.js

정적 export 결과를 사용한다. 자산 경로는 `./_next/` 형태여야 한다.

<a id="vite"></a>

## Vite

build 결과를 사용한다. 자산 경로는 `./assets/` 형태여야 한다.

<a id="plain-html"></a>

## 순수 HTML

빌드 단계가 없다면 `index.html`과 자산을 같은 상대 경로 구조로 압축한다.
