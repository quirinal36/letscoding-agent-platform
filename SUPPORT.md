# Support

For reproducible product defects and installation questions, open a GitHub issue at
https://github.com/quirinal36/letscoding-agent-platform/issues. Include the Plugin version,
policy version, stable finding/error code, operating system, Node.js version, and redacted request
ID when available.

Do not include project source, ZIP bytes, `.env` values, tokens, personal data, or student
information. Security reports must use the private route in `SECURITY.md`, not a public issue.

The first release builds and validates a local ZIP only. It does not register, upload, publish, or
delete a Lounge work. Operational status and incident updates are maintained in repository issues
until a dedicated status page is approved.
